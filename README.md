# Batched & Bulletproof

**Built for the file that tries to break it.**

An interactive walkthrough of a production desktop automation that turned a
1,000+ file Microsoft Project documentation job into an unattended,
self-verifying batch run — including a simulated replay of a real batch,
complete with the file that fails on purpose.

**Live page:** https://rwhale.github.io/batched-and-bulletproof-demo/

Every file name, program name, environment name, and data value on the page is
fictional. The mechanisms, behaviors, log lines, and timings are drawn from
real, live-verified runs of the production tool.

Built by [Rob Hale](https://www.linkedin.com/in/halerobert/) — architecture,
safety design, and field testing — working with AI as an engineering partner.
